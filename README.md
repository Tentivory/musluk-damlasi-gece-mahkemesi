# Musluk Damlasi Gece Mahkemesi

Resmi ad: **Musluk Damlasi Gece Mahkemesi**
Gayriresmi ad: *o ses yine basladi*
Dosya no: `MDGM-2026/0314`
Statu: Acik. Uyku kapali.

Bu depo, gece 03:14 sularinda lavabodan gelen tek damlayi ciddiye alan, tutanak tutan ve kimseyi uyandirmadan hukum veren ulusal bir gece yargisidir. Tesisatci cagrilmaz. Havlu katlanmaz. Sadece damla sayilir.

Patates bu dosyada yoktur. Varsa da delil degildir, yanlis dosyadir.

## Neden var

Cunku musluk tamir edilmez. Cunku conta bir gundur degil, bir medeniyet boyu gevsektir. Cunku insan kalkip vanayi cevirmek yerine yorganin altinda savci olur.

Bilim bunu *akustik israr* diye adlandirir. Bu repo bunu *sanik* diye adlandirir.

## Kurulum

Python 3 yeter. Baska bagimlilik yok. Musluk da yok. Hayal gucu var.

```bash
git clone https://github.com/Tentivory/musluk-damlasi-gece-mahkemesi.git
cd musluk-damlasi-gece-mahkemesi
python3 mahkeme.py
```

Belirli bir gece saati icin:

```bash
python3 mahkeme.py --saat 03:14 --damla 17 --sikayetci yorgan
```

JSON tutanak isteyen resmi makamlar icin:

```bash
python3 mahkeme.py --json
```

## Durusma akisi

1. Saat gece yarisini gecer.
2. Damla kendini tanik olarak da sanik olarak da dinletir.
3. Yorgan itiraz eder, uyku red oyu verir.
4. Mahkeme conta hakkinda giyabi karar verir.
5. Kimse kalkmaz. Karar kesinlesir. Damla devam eder.

Bu bir bug degildir. Bu icraattir.

## Hukuki dayanak (uydurma ama tok)

- Gece Sesleri Usul Kanunu, m. 3: *Damla, susmayi reddederse sanik sayilir.*
- Yorgan Icisraati, m. 1: *Kalkmak son caredir, once tutanak.*
